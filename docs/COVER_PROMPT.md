# FEATABLE — 인터뷰 표지(훅 카드) 생성 프롬프트

인스타그램형 인물 중심 인터뷰 표지를 GPT 이미지 생성에 만들게 하는 템플릿.
인물 사진(+로고)을 업로드하고 따옴표 안의 세 줄 텍스트만 바꿔 사용한다.
2026-08-22 실제 생성 테스트를 거쳐 확정한 버전.

> 상세페이지용 이미지 프롬프트는 폐기함 (2026-08). 콘텐츠 기본 단위를
> 상세페이지가 아닌 인물 중심 인터뷰 게시물로 전환하면서, 표지 프롬프트만 유지.

---

```
첨부한 인물 사진을 배경으로 쓰는 세로형(4:5) 인터뷰 표지 이미지를 만들어줘.

[규칙]
- 사진 원본을 그대로 유지할 것. 인물의 얼굴, 몸, 배경을 절대 수정·보정·재생성하지 말고, 그 위에 그래픽 요소만 얹을 것.
- 필요하면 4:5 비율에 맞게 크롭만 허용. 인물 얼굴이 상단 2/3 안에 오도록.

[텍스트 오버레이 — 위치 엄수]
- 세 줄 텍스트 블록은 반드시 이미지 하단에 붙일 것: 마지막 줄의 아래 여백이 이미지 높이의 약 5%, 텍스트 블록 전체는 이미지 하단 25% 영역 안에만 위치. 인물의 가슴이나 중앙에 텍스트를 두지 말 것.
- 왼쪽 여백은 이미지 폭의 약 6%, 왼쪽 정렬.
각 줄의 내용은 따옴표 안의 글자만 정확히 그대로 쓰고, 따옴표나 다른 괄호는 절대 추가하지 말 것:
1줄: "03년생, 24살"
2줄: "연구용 AI 스타트업 대표"
3줄: "<카라멜 랩 이찬서>"

- 1~2줄: 아주 굵은 한글 고딕체(Pretendard Black 느낌), 흰색, 큰 사이즈. 부드러운 검은 그림자로 또렷하게.
- 3줄: 꺾쇠괄호 < > 는 3줄에만 포함된 디자인 요소이므로 그대로 렌더링. 1~2줄보다 훨씬 작게, 흰색.
- 사진 하단 1/4에는 반드시 은은한 어두운 그라데이션을 깔아 텍스트 가독성을 확보할 것. 검은 띠처럼 덮지 말고 자연스럽게 어두워지는 정도로, 사진 속 사물은 계속 보이게.
- 글자는 오타 없이 정확하게.

[로고 스티커]
- 함께 첨부한 로고를 검은색 완전한 원형 배지로 만들어 인물 어깨 옆쪽, 이미지 세로 기준 중앙쯤에 배치. 얼굴을 가리지 말 것. 접힌 모서리나 입체 효과 없이 깔끔한 평면 원. 5도 정도만 기울일 것. 크기는 화면 폭의 25% 내외.
- (로고 없으면 이 항목은 무시)

[전체 느낌]
인스타그램에서 스크롤을 멈추게 하는 인물 중심 인터뷰 카드. 잡지 표지처럼 깔끔하고, 장식 요소는 텍스트와 스티커 외에 추가하지 말 것.
```

## 바꿀 곳 (따옴표 안 내용만)

| 줄 | 내용 | 예시 |
| --- | --- | --- |
| 1줄 | 출생연도, 나이 | `03년생, 24살` |
| 2줄 | 한 줄 정체성 (숫자 훅이 있으면 더 강함) | `1년만에 4개 지점, 스터디라운지 대표` |
| 3줄 | `<브랜드명 이름>` 꺾쇠 포함 | `<카라멜 랩 이찬서>` |

## 사진 고르는 기준

- 얼굴이 잘 보이는 세로 사진
- 하단에 텍스트가 들어갈 여백이 있는 컷 (그라데이션이 자연스럽게 깔림)
- 작업/일상 공간에서 찍힌 컷이 스튜디오 컷보다 반응이 좋음

## 알려진 한계

- **얼굴 변형**: GPT 이미지 생성은 사진 전체를 다시 그리는 방식이라, 프롬프트로
  금지해도 얼굴이 미세하게 달라진다. 완전한 방지는 불가능.
- **위치 편차**: 같은 프롬프트도 생성마다 레이아웃이 조금씩 다르게 나올 수 있다.
- 근본 해결은 원본 사진 위에 텍스트·스티커만 합성하는 훅 카드 생성기(웹 도구)를
  Featable에 내장하는 것. 인터뷰형 게시물 기능과 함께 구현 예정.
