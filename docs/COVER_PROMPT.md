# FEATABLE — 인터뷰 표지(훅 카드) 생성 프롬프트

인스타그램형 인물 중심 인터뷰 표지를 GPT 이미지 생성에 만들게 하는 템플릿.
인물 사진(+로고)을 업로드하고 `[대괄호]` 세 곳만 바꿔 사용한다.

> 상세페이지용 이미지 프롬프트는 폐기함 (2026-08). 콘텐츠 기본 단위를
> 상세페이지가 아닌 인물 중심 인터뷰 게시물로 전환하면서, 표지 프롬프트만 유지.

---

```
첨부한 인물 사진을 배경으로 쓰는 세로형(4:5) 인터뷰 표지 이미지를 만들어줘.

[규칙]
- 사진 원본을 그대로 유지할 것. 인물의 얼굴, 몸, 배경을 절대 수정·보정·재생성하지 말고, 그 위에 그래픽 요소만 얹을 것.
- 필요하면 4:5 비율에 맞게 크롭만 허용. 인물 얼굴이 상단 2/3 안에 오도록.

[텍스트 오버레이]
사진 하단에 아래 세 줄을 배치:
1줄: "[01년생, 26살]"
2줄: "[웹 포토부스 플랫폼 대표]"
3줄: "<[freqz 김보아]>"

- 1~2줄: 아주 굵은 한글 고딕체(Pretendard Black 느낌), 흰색, 큰 사이즈, 두 줄 왼쪽 정렬 또는 중앙 정렬. 부드러운 검은 그림자를 넣어 어떤 배경에서도 또렷하게.
- 3줄: 꺾쇠괄호 < > 포함 그대로, 1~2줄보다 훨씬 작게, 흰색.
- 텍스트 뒤 사진 하단에는 은은한 어두운 그라데이션을 깔아 가독성 확보. 사진 전체를 어둡게 하지는 말 것.
- 글자는 오타 없이 정확히 위 문구 그대로 렌더링할 것.

[로고 스티커]
- 함께 첨부한 로고를 검은 원형 스티커 배지로 만들어 인물 어깨 옆쪽에 살짝 겹치게 배치. 5~10도 정도 기울여 스티커 붙인 느낌으로. 크기는 화면 폭의 25% 내외.
- (로고 없으면 이 항목은 무시)

[전체 느낌]
인스타그램에서 스크롤을 멈추게 하는 인물 중심 인터뷰 카드. 잡지 표지처럼 깔끔하고, 장식 요소는 텍스트와 스티커 외에 추가하지 말 것.
```

## 바꿀 곳

| 자리 | 내용 | 예시 |
| --- | --- | --- |
| 1줄 | 출생연도, 나이 | `01년생, 26살` |
| 2줄 | 한 줄 정체성 (숫자 훅이 있으면 더 강함) | `1년만에 4개 지점, 스터디라운지 대표` |
| 3줄 | 브랜드명 + 이름 | `<freqz 김보아>` |

## 사진 고르는 기준

- 얼굴이 잘 보이는 세로 사진
- 하단에 텍스트가 들어갈 여백이 있는 컷 (그라데이션이 자연스럽게 깔림)
- 작업/일상 공간에서 찍힌 컷이 스튜디오 컷보다 반응이 좋음
