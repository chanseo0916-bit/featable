# FEATABLE — 상세페이지 이미지 생성 프롬프트 (GPT 이미지용)

와디즈식 세로 스토리텔링 상세페이지에 들어가는 이미지들을 GPT 이미지 생성(또는 다른 이미지 모델)에 바로 붙여넣어 만들 수 있는 템플릿.
`{중괄호}` 부분만 제품 정보로 바꿔서 사용한다.

> 향후 계획: 브랜드 등록 위저드의 AI Feature 단계에서 Founder의 답변으로 이 프롬프트들을 **자동 완성해서 제공**한다. (Claude 담당)

---

## 공통 스타일 규칙 (모든 프롬프트 끝에 붙이기)

```
스타일: 미니멀한 한국 스타트업 브랜드 상세페이지 이미지. 완전한 흰색 배경(#FFFFFF),
포인트 컬러는 브랜드 오렌지(#EF4125) 하나만 사용. 깔끔한 여백, 부드러운 자연광,
과장 없는 사실적인 연출. 텍스트는 넣지 말 것.
```

- **텍스트 없는 이미지**를 기본으로 한다. 문구는 웹에서 HTML 텍스트로 얹는 게 SEO·수정에 유리함
- 세로 상세컷 비율: **4:5 또는 3:4** / 히어로·썸네일: **16:9 또는 1:1**
- 같은 제품의 이미지들은 한 세션(같은 대화)에서 연속 생성해야 톤이 유지됨

---

## 1. 히어로 / 대표 이미지 (16:9 또는 1:1)

```
{제품명}의 대표 제품 사진. {제품 형태·재질 묘사, 예: 알루미늄 바디의 휴대용 에스프레소 머신}.
흰색 스튜디오 배경 중앙에 제품 하나만 배치하고, 오렌지색 소품 {예: 컵, 리본, 받침} 하나로 포인트.
45도 위에서 내려다보는 앵글, 부드러운 그림자.
```

## 2. 인트로 무드컷 (4:5)

```
{타깃 고객, 예: 20대 대학생}이 {사용 장면, 예: 카페 창가에서 노트북으로 작업하며}
{제품명}을 자연스럽게 사용하는 라이프스타일 사진. 밝고 따뜻한 자연광,
흰색과 우드톤 위주의 공간, 오렌지색 소품 하나가 은은하게 보임. 필름 감성보다는 깨끗한 현대적 톤.
```

## 3. 문제 제기 컷 (4:5)

```
{문제 상황, 예: 책상 위에 어지럽게 흩어진 종이 노트와 포스트잇 더미} 를 보여주는 연출 사진.
답답하고 비효율적인 느낌이 들도록 약간 어수선하게, 하지만 지저분하지 않게.
채도를 살짝 낮춘 회색조 톤 (이 컷만 예외적으로 오렌지 포인트 없음 — 솔루션 컷과 대비 목적).
```

## 4. 솔루션 컷 (4:5)

```
3번과 같은 공간·같은 앵글에서, {제품명}으로 문제가 해결된 정돈된 모습.
{해결된 상태 묘사, 예: 깨끗한 책상 위 노트북 화면에 정리된 인터페이스}.
밝은 흰색 톤에 오렌지 포인트가 선명하게 살아있는 대비 연출.
```

## 5. 기능 상세 컷 — 기능당 1장 (1:1 또는 4:5)

```
{제품명}의 {기능명, 예: 원터치 접이식 구조} 를 보여주는 클로즈업 제품 사진.
흰색 배경, 해당 부분에 초점을 맞춘 매크로 촬영 느낌, {기능이 작동하는 순간 묘사}.
오렌지색 화살표나 라벨 없이 구도 자체로 기능이 보이게.
```

## 6. 사용 장면 / 라이프스타일 컷 (4:5)

```
{다른 상황, 예: 아침 출근길 지하철에서} {타깃 고객}이 {제품명}을 사용하는 두 번째 라이프스타일 컷.
2번 인트로 컷과 같은 인물·같은 톤을 유지하되 장소만 다르게. 자연스러운 스냅 사진 느낌.
```

## 7. 구성품 / 스펙 컷 (1:1)

```
{제품명}의 구성품 플랫레이(flat lay) 사진. 흰색 배경 위에
{구성품 나열, 예: 본체, 충전 케이블, 파우치, 설명서}를 격자에 맞춰 가지런히 배치.
정확히 수직으로 내려다본 탑뷰, 각 물건 사이 일정한 여백, 오렌지색 파우치가 포인트.
```

## 8. Founder / 팀 컷 (4:5)

```
{연령대·분위기, 예: 20대 중반의 밝은 인상} 창업가의 자연스러운 프로필 사진.
{작업 공간, 예: 화이트톤 사무실}에서 카메라를 향해 편안하게 미소 짓는 상반신 컷.
과하지 않은 보정, 신뢰감 있는 톤, 배경은 살짝 아웃포커스.
```

## 9. 마무리 / CTA 배너 배경 (16:9)

```
{제품명}이 {상징적 장면, 예: 창가 햇살 아래 놓인 모습}으로 여운을 주는 클로징 컷.
화면 오른쪽 절반은 텍스트를 얹을 수 있게 흰 여백으로 비워둘 것. 미니멀하고 감성적인 분위기.
```

---

## 사용 순서 (Founder 안내용)

1. 위 1→9 순서대로 한 대화 안에서 생성 (톤 유지)
2. 생성된 이미지를 상세페이지 스토리 블록 순서에 맞춰 업로드
3. 문구(제목, 설명)는 이미지에 넣지 않고 Featable 에디터에서 텍스트로 입력
